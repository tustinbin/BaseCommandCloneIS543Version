# Wiki extract — Perks

Source: Namu perk CSV `…71a1d9ce996cd19372.csv` + §5. Confidence: `observed` (wiki).

| id | Name | Definition |
|----|------|------------|
| behemoth | Behemoth | Enemy: +1 Attack and +1 Firepower **per turn**. Player: when engaged, +1 Attack and +1 Firepower per turn, **cap +3**. |
| concealment | Concealment | Spawn at **range 2** instead of 4. |
| first_strike | First Strike / Preemptive | Attack first when engaged; if both have it, **player** goes first. |
| rage | Rage / Fury | +1 Firepower each time hit (including map weapons). |
| heavy_weapons | Heavy Weapons | First attack in engagement **ignores** opponent evasion. |
| ion_weapon | Ion Weapon | Enemy: +1 vs aircraft; ignore base shield (not overcharge). Player: +1 vs aircraft; ignore enemy unit shields. |
| luck | Luck / Good Luck | Higher critical-hit rate (“fatality rate is high”). |
| overload | Overload | First attack opportunity spends **all** attacks at once. |
| protect | Protect / Protected | Ignore first damaging hit; does not block instant-kill (Thermal Imploder); ≠ shield layer. |
| recovery | Recovery | Full HP at each turn start. |
| resurrection | Resurrection | After dying once and battle ends, respawn without this perk. |
| speed_acceleration | Speed Acceleration | Advance **2** spaces per turn. Default on Probe Droid & Speeder Bike. |
| squad_leader | Squad Leader | Enemy: spawn with +1 extra unit. **Player: after battle, draw a new star card.** |
| important_goal | Important Goal | Must attack the unit with this perk. |

## Non-perk: unit shields

Some sieges give enemies shield layers: block N attacks; regen +1/turn end; Ion Grenade clears shields in coordinate.

## Video-note conflicts (wiki wins)

- Player Squad Leader draws **star** card (not unit card).
- Video “Agility dodge chance” is **not** wiki model — evasion is flat FP reduction; Miss is separate RNG.
